# Anko Keyboard

A Japanese keyboard for Android by **tslab** that is **flick-input only** — no QWERTY, no romaji typing. Built on the Mozc conversion engine with context-aware automatic conversion.

- Flick-only kana input with a split layout for one-handed portrait typing
- Automatic conversion that follows your sentence context
- User dictionary, names & places dictionary
- Clipboard history (up to 20 items)
- 8 flat themes
